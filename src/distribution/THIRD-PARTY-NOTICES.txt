Third-party dependency material
===============================

The lib directory contains the unmodified runtime dependency JARs resolved by
the Gradle build. License, notice, and dependency files embedded by those
artifacts remain available inside each JAR under META-INF. Copies of embedded
META-INF/LICENSE*, META-INF/NOTICE*, and META-INF/DEPENDENCIES* files are also
provided under third-party-licenses/<jar-name>/ for convenient review.

This notice describes dependency material only. MegaMek Launcher's source
code license is in LICENSE.code; neither document grants trademark rights.

Bundled fonts
-------------

The launcher JAR bundles these fonts under org/megamek/launcher/design/fonts/,
